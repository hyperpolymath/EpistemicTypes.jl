== Changelog

All notable changes to this project will be documented in this file.

The format is based on https://keepachangelog.com/en/1.1.0/[Keep a
Changelog], and this project adheres to
https://semver.org/spec/v2.0.0.html[Semantic Versioning].

No release has been tagged. `0.1.0` is the version in `Project.toml` and the
release recorded in `CITATION.cff`.

=== [Unreleased]

==== Changed

* *Breaking:* `disambiguate_zero` now takes the sample's total read count
  (library size) and a `ThresholdPolicy`, as `disambiguate_zero(sample_depth,
  pol)`. The method that took a `Warrant` is removed. It compared the warrant's
  per-feature `depth`, which is 0 in a zero cell, so it could never return
  `true_absence`. Marked `POST-RECOVERY FIX (4)` in `src/core/Epistemic.jl`.
* The Julia compatibility floor is 1.10 (was 1.9), and CI tests that floor.
* The package UUID was re-minted as a UUIDv8 (estate ADR-008 amendment D320).
  The previous UUIDv5 is in the git history of `Project.toml`.
* *Breaking:* `can_merge` no longer chooses a collapse rank. When the database
  key or release differs, it refuses with `collapse_rank_required` until the
  caller passes `collapse_to`, and refuses with `collapse_rank_not_in_both`
  when either ladder lacks that rank. The old code collapsed to the coarsest
  shared rank (`Domain` for PR2 against SILVA). Marked
  `POST-RECOVERY FIX (5)`.
* The wire form is now `echo:v2`: every value is percent-encoded, so a field
  holding `&` or `=` round-trips. `parse_avec_fibre` still reads `echo:v1`, and
  a receipt's `v` records the tag it was read from. Marked
  `POST-RECOVERY CHANGE (6)`.
* `bulk_verify!` is renamed `bulk_verify`, because it does not modify its
  input. The old name is a deprecated alias.
* Docstrings, tests and documents say "digest", not "signature": `sig` is an
  unkeyed SHA-256 digest, so it detects accidental edits, not deliberate ones.

==== Added

* `ThresholdPolicy.sample_depth_min`, the library size at which a zero cell
  counts as an absence. It has no default; `disambiguate_zero` throws
  `ArgumentError` until it is set.
* `docs/ARCHITECTURE.adoc`, and decision records, measured costs and current
  limits in `docs/EXPLAINME.adoc`.
* An abstract and subject keywords in `CITATION.cff`, and the author's ORCID.

==== Fixed

* `can_merge` refuses with `no_common_rank` when two releases of one database
  share no rank. It returned `OK_COLLAPSE` with `collapse_to === nothing`.
  Marked `POST-RECOVERY FIX` in `src/core/Epistemic.jl`.
* The README gave the Julia floor as 1.9.
* `CHANGELOG.adoc`, `STATE.a2ml` and the `CITATION.cff` keywords described the
  repository template this package was minted from, not the package.

==== Removed

* `.github/workflows/rust-ci.yml`. The package has no Rust code.
* *Breaking:* the `TPUBackend`, `NPUBackend` and `VPUBackend` stubs, which only
  threw an error. Coprocessor contracts live in CoprocessorRuntime.jl.
  Marked `POST-RECOVERY CHANGE (7)`.
* The template's documentation and the unwired Idris2/Zig skeleton under
  `src/`. `src/` holds only the package.

=== [0.1.0] - 2026-09-23

==== Added

* `module Epistemic` (`src/core/Epistemic.jl`), restored from the design
  thread "Clades and Other Prompts" with the two `RECOVERY FIX` changes it
  needed to run: the missing `using Base64`, and the `replace` call in
  `b64url`.
* Receipts: `Standpoint`, `Warrant`, `ProjectionY`, `Receipt`,
  `make_receipt`, `verify_receipt`, and the `avec_fibre` wire form.
* Decisions: `ThresholdPolicy`, `passes_gates`, `highest_warranted_rank`,
  `epi_status`, `disambiguate_zero`, `residual_info`, `can_merge` and
  `lowest_common_rank`.
* `CPUBackend` with `bulk_verify!`, and TPU, NPU and VPU stubs that refuse.
* The test suite: Aqua package-shape checks, then behaviour tests in
  `test/cases/`.
